# Research Opportunity Hub

A central discovery platform for UC Berkeley undergraduate research opportunities
(URAP, SURF, SUPERB, Haas Scholars, Rose Hills, Discovery Initiative, SURD, and more).

## Run it

Open `index.html` in any browser. No build step, no dependencies — it's a single
self-contained static page. (Or enable GitHub Pages on this repo to host it.)

## Features

- Search + filter by category, eligibility, and compensation type
- Deadline countdowns with color-coded urgency indicators
- Detail modal per opportunity with official application links
- **Add to Google Calendar**: one-click button on every listing with a future
  deadline opens a pre-filled Google Calendar event (all-day, title, description,
  official source link). No login or API key needed.

## Data honesty notice

> **Demo dataset (v1).** Only 2 of the 11 listing deadlines are real/verified; the
> rest are representative dates carried over from the prototype. Always confirm
> details on the linked official page before applying. Calendar events created
> from representative dates carry a "verify on the official page first" warning.
