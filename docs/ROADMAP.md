# Roadmap

## Phase 1 — Interactive frontend prototype ✅ (current)

- Discovery board with 11 Berkeley research opportunity listings
- Full-text search, filters (major / research area / department / deadline window), and sorting
- Visual deadline system (color-coded urgency)
- Detail modals with application requirements, funding, and official source links
- One-click **Add to Google Calendar** on listings with future deadlines
- "Suggest an Opportunity" / "Report an Update" entries, last-verified dates
- Single-file static page; public demo link + GitHub repository

## Phase 2 — User testing 🔄 (next)

- Collect feedback from Berkeley undergraduates on discoverability, clarity, and missing listings
- Fix paper cuts; expand and verify the dataset against official sources

## Phase 3 — Backend & admin tooling ⏸️ (on hold)

- Admin workflows: add / edit / remove opportunities, update deadlines and eligibility, track verification dates, mark rolling vs. fixed deadlines
- Deferred by team decision (2026-10-19): frontend polish and user testing come first
